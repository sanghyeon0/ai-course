\## 어텐션이란?



어텐션은 AI가 문장을 읽을 때 모든 단어를 똑같이 중요하게 보지 않고 중요한 단어에 더 집중하는 방법이다.

예를 들어 문장의 한 단어를 이해할 때 주변에 있는 다른 단어들과의 관계를 함께 살펴본다.

이를 통해 문장에서 중요한 단어와 단어 사이의 관계를 파악할 수 있다.

트랜스포머 모델은 이런 어텐션을 이용해 문장의 맥락을 효과적으로 이해한다.

쉽게 말하면 어텐션은 AI가 문장을 읽으면서 어떤 단어를 더 중요하게 볼지 결정하는 방법이다.
